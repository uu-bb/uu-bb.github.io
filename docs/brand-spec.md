## 使用边界

- 封面采用原创的睡眠 / 唤醒双空间构图，不复刻参考作品中的人物、文字、标志或具体陈设。
- 图片中不烘焙标题、姓名、岗位和按钮文字，所有信息由网页排版。
- 项目图片采用“微场景叙事”，并用图注明确左、中、右所代表的输入、处理和结果。
- SideRays 只作为首屏气氛层，不遮挡人物、品牌标题、导航或操作入口；移动端与减弱动效模式使用静态柔光。
- 3D 区使用“角色 + 能力导览”双栏结构；角色提供记忆点，导览必须连接真实项目、核验证据与案例页，不能只作为模型陈列。
- 联系区 OptionWheel 只切换沟通意图和邮件主题；邮箱复制、GitHub、简历查看与下载始终保持为独立快捷入口。
- 转盘使用曲线、轻微模糊和位置变化表达层级，不以低对比度或低透明度牺牲可读性。
- 事实、项目数字与核验日期继续由公开数据合同提供，不写入视觉资产。

## 项目讲解页

- 固定为八层阅读顺序：项目理解、对象与场景、用户流程与功能、架构、关键取舍、代表代码、证据与失败路径、个人贡献。
- 顶部讲解目录使用稳定锚点，键盘和触屏都能直接进入任一章节；章节滚动定位不得被固定导航遮挡。
- 流程图只表达用户任务的前后关系，架构图只表达系统分工，两者不能混成一张技术名词墙。
- 代表代码控制在 28 行以内，只展示真正影响产品边界或工程判断的片段。
- 每段代码必须同时解释输入、判断、输出和设计原因，不逐行复述语法。
- 项目测试数字仍只通过 `evidenceIds` 引用证据记录，项目文案和代码说明不得重复手写测试数字。
- 小u鱼只公开脱敏的 V1 代表代码，不发布本地目录、文件名、私有来源映射或后续版本实现。
