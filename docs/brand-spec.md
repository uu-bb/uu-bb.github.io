## 使用边界

- 封面采用原创的睡眠 / 唤醒双空间构图，不复刻参考作品中的人物、文字、标志或具体陈设。
- 图片中不烘焙标题、姓名、岗位和按钮文字，所有信息由网页排版。
- 项目图片采用“微场景叙事”，并用图注明确左、中、右所代表的输入、处理和结果。
- SideRays 只作为首屏气氛层，不遮挡人物、品牌标题、导航或操作入口；移动端与减弱动效模式使用静态柔光。
- 事实、项目数字与核验日期继续由公开数据合同提供，不写入视觉资产。
